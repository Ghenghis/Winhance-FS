System Architecture

Multi-layer architecture combining Rust performance with .NET flexibility

[WPF Presentation Layer] Modern UI with MVVM pattern, tabbed file manager, TreeMap visualizations
[Core Services] File operations, indexing, search, organization logic
[AI Agent Layer] Classifier, Organizer, Analyzer, Search AI, Model Manager, Transaction Agent
[Infrastructure] MCP server, self-healing, update system, settings management
[Rust Backend] MFT scanner, USN journal, xxHash3 engine, SIMD-optimized search
