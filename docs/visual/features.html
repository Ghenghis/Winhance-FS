Smart Search

SearchService · ISearchService

Complete
  • Indexed-first — calls _nexusIndexer.SearchAsync() when MFT index is available, falls back automatically to filesystem scan
  • Streaming via SearchStreamingAsync() — fires Action<SearchResult> onResult callback per-file, never buffers the full result set
  • Regex support — SearchOptions.UseRegex compiles the query as a Regex with optional RegexOptions.IgnoreCase
  • Relevance scoring — exact match=100, starts-with=80, contains=60, character-overlap=0–40
  • GetSuggestionsAsync() — blends recent searches (last 50) with live index hits
  • Multi-field sort — Name, Size, DateModified, DateCreated, Extension, Path, or Score
  • Filter pipeline — MinSize/MaxSize, date ranges, extension allow/deny lists, path exclusions
IndexedSearch FsSearch Streaming Regex Scoring 50 Recent

Archive Tools

ArchiveService · IArchiveService

Partial
  • GetArchiveInfoAsync() — entry count, folder count, uncompressed size, compression ratio from ZIP headers
  • ListContentsAsync() — directory-aware browsing with virtual subfolder path prefix, sorted dirs-first
  • ExtractAllAsync() / ExtractEntriesAsync() — preserve timestamps, preserve directory structure, overwrite control, exclude patterns, per-entry IProgress
  • ExtractToStreamAsync() — streams a single entry directly to any Stream without temp files
  • CreateArchiveAsync() / AddToArchiveAsync() — 4 compression levels, exclude patterns, base-folder option
  • TestArchiveAsync() — reads every byte of every entry to verify CRC integrity
  • SearchAsync() — wildcard→regex pattern matching against entry name and full path
  • 7z / RAR — format objects defined with CanCreate=false; SevenZipArchiveHandler stub exists for future implementation

Duplicate Finder

DuplicateFinderService · IDuplicateFinderService

Complete
  • Stage 1 — Size grouping — instant pre-filter, eliminates unique-size files with zero I/O
  • Stage 2 — MD5 quick hash — samples first+last 64 KB + file size bytes; fast for large files via ComputeQuickHashAsync()
  • Stage 3 — SHA-256 full hash — VerifyWithFullHashAsync() confirms true duplicates with 80 KB streaming buffer
  • Byte comparison — AreFilesIdenticalAsync() uses 64 KB chunked SequenceEqual as final arbiter
  • Fuzzy name matching — CalculateStringSimilarity() via LevenshteinDistance() normalized to [0,1]
  • 7 keep strategies — KeepFirst, KeepLast, KeepOldest, KeepNewest, KeepShortestPath, KeepLongestPath, KeepSelected
  • Safe delete — Recycle Bin via Microsoft.VisualBasic.FileIO.FileSystem.DeleteFile by default
MD5 Quick SHA-256 Full Levenshtein Fuzzy Names RecycleBin 7 Strategies

WinGet Manager

WinGetService · IWinGetService

Complete
  • Direct process invocation — spawns winget.exe with ProcessStartInfo, captures stdout line-by-line via OutputDataReceived
  • PATH → AppX fallback — ResolveWinGetPathAsync() first checks PATH, then Get-AppxPackage -Name Microsoft.DesktopAppInstaller
  • 8 install exit codes handled — package not found, already in progress, user cancelled, needs admin, no disk space, already installed, source unavailable, access denied
  • Source self-repair — on exit code -1978335230 (sources corrupted), triggers WinGetInstallationScript.InstallWinGetAsync() and retries
  • WinGetOutputParser — live progress extraction from winget stdout, detects connectivity issues during download
  • EnsureWinGetUpToDateAsync() — runs winget install Microsoft.AppInstaller, handles update-via-Store flow with 10-second poll loop
  • 13 network error keywords — network, timeout, connection, dns, ssl, tls, proxy, certificate, offline, and more
Direct Exec AppX Fallback 8 Exit Codes Self-Repair Live Parser Network Guard

Batch Rename

BatchRenameService · IBatchRenameService

Complete
  • 7 rule types — Prefix insertion, Suffix insertion, Regex find-and-replace, Counter padding (01, 02…), Date stamp injection, Extension change, Case transform (lower/UPPER/Title)
  • Live preview — PreviewRenameAsync() returns before/after pairs without touching the filesystem
  • Collision detection — validates no two files would collide in the target directory before committing
  • Undo support — stores original→new name mapping; UndoAsync() reverses the operation
  • Rule chaining — multiple rules applied sequentially in order, enabling complex transformations
  • IProgress reporting — per-file progress stream during multi-hundred-file operations
