Section 06

Navigation Features

NavigationViewModel manages a dual-stack history (BackHistory / ForwardHistory) capped at 50 entries, with lazy loading of sub-nodes via LoadNodeChildrenAsync().

💾 C: › Users › User › Documents
C:\Users\User\Documents
⬅️
Back / Forward
Dual ObservableCollection<NavigationHistoryViewModel>. NavigateBackAsync() pops from BackHistory and pushes current to ForwardHistory.
📍
Breadcrumb Bar
Segments derived from CurrentPath. Each crumb calls _addressBarService.NavigateAsync(path).
⬆️
Navigate Up
NavigateUpAsync() calls Directory.GetParent(CurrentPath) — no path string splitting needed.
🌳
Tree Navigation
Root groups: This PC, Quick Access, Network. Nodes lazy-load children with ExpandNodeAsync(), capped at 100 dirs.
🏠
Home Navigation
NavigateHomeAsync() resolves to Environment.SpecialFolder.UserProfile — OS-agnostic.
🆕
Open in New Tab
OpenInNewTabAsync(node) delegates to _tabService.CreateTabAsync(node.FullPath) and increments node.AccessCount.

GetPropertiesAsync() — FileManagerService.cs
var properties = new FileProperties();

// Timestamps from FileInfo
properties.DateCreated = fileInfo.CreationTime;
properties.DateModified = fileInfo.LastWriteTime;
properties.DateAccessed = fileInfo.LastAccessTime;

// Attributes flags
properties.IsReadOnly = fileInfo.IsReadOnly;
properties.IsHidden = fileInfo.Attributes
    .HasFlag(FileAttributes.Hidden);
properties.IsSystem = fileInfo.Attributes
    .HasFlag(FileAttributes.System);

// SHA-256 inline hash
using var stream = File.OpenRead(path);
using var sha256 = SHA256.Create();
var hash = sha256.ComputeHash(stream);
properties.Hash = BitConverter
    .ToString(hash)
    .Replace("-", "")
    .ToLowerInvariant();
